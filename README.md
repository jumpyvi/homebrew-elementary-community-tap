# Jumpyvi Elementary-community-tap

## How do I install these formulae?

`brew install jumpyvi/elementary-community-tap/<formula>`

Or `brew tap jumpyvi/elementary-community-tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jumpyvi/elementary-community-tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
